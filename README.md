# Recruitment Platform

This repository contains a React frontend and a separate FastAPI backend. The backend was created from scratch because the linked GitHub repository was empty when inspected.

Start with [`backend/README.md`](./backend/README.md) for API setup and [`frontend/README.md`](./frontend/README.md) for the UI. [`backend/API_CONTRACT.md`](./backend/API_CONTRACT.md) documents implemented endpoints; [`frontend/API_CONTRACT.md`](./frontend/API_CONTRACT.md) retains broader frontend integration requirements. The root `.venv/` is for the Python backend; the frontend runs on Node.js.
